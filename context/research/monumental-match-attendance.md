# Attendance for the MUT and Monumental comparison

Use 39,222 spectators at both sites for a comparison based on the Superclásico of 31 August 2025. Colo-Colo played Universidad de Chile at the Estadio Monumental at 15:00 local time. The match reports give the same count. [En El Camarín](https://enelcamarin.cl/joomsport_match/primera-division-de-chile-liga-de-primera-itau-2025-colo-colo-vs-universidad-de-chile/) · [Transfermarkt](https://www.transfermarkt.com/csd-colo-colo_club-universidad-de-chile/index/spielbericht/4562729)

Cooperativa's match report describes almost 40,000 spectators. The pre-match limit was 42,000. Use the reported turnout to set attendance. [Cooperativa](https://www.cooperativa.cl/noticias/deportes/futbol/superclasico/colo-colo-desperto-ante-la-u-para-conquistar-el-superclasico-198-y/2025-08-31/165757.html) · [AS Chile](https://chile.as.com/futbol/colo-colo-celebra-antes-del-superclasico-decision-polemica-n/)

Keep the assumed end time and attendee origins fixed when comparing sites. The turnout is a historical input. The return trips are model estimates. The match reports provide neither attendee origins nor travel modes.
