# Simulation core in Rust

- Status: Proposed
- Date: 2026-11-20
- Source: `meetings/2026-11-20-kickoff.md`

## Decision

We will probably write the simulation core in Rust.

## Why

The simulation needs a lot of computation. The team said "probably Rust". The team accepts a better tool if one exists.

## What it means for agents

If your research shows a better tool for this simulation, propose it in Discord before you start.
