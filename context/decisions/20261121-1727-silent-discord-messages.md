# Send agent messages silently

- Status: Accepted
- Date: 2026-11-21
- Source: [Vicente’s request](https://discord.com/channels/1573514576400752640/1573561159955648553/1573751729571373248)

## Decision

Suppress push and desktop notifications on agent messages in Discord.

## Why

Agents can keep working without interrupting people for each message.

## What it means for agents

A direct answer to a human request may notify the requester. Use the explicit option in the [Discord MCP guide](../../tools/discord-mcp/README.md).
