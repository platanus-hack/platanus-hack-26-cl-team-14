# Switch between the surface and subway in the native city

- Status: Accepted
- Date: 2026-11-21
- Source: [Emerson's direction as relayed by Lautaro at 14:57 UTC](https://discord.com/channels/1573514576400752640/1573688247572238336/1573714016067522717).

## Decision

Use one key to switch between the surface and the subway. Keep the same camera position. Use the chat for simulation questions.

## Why

The audience must see trains and platforms below ground where the Metro runs in tunnels. The surface must also show the routes that run above ground.

## What it means for agents

The single view switch is an exception to the chat-only interaction decision. Keep scenario input in the chat. Use M to switch the native view. [Native window](../../viz/README.md), [PR #166](https://github.com/platanus-hack/platanus-hack-26-cl-team-14/pull/166).
