# Decisions stay in the repository

- Status: Accepted
- Date: 2026-11-21
- Source: human request in chat

## Decision

Keep decisions in `context/decisions/`. Delete the Discord `#decisions` channel.
Keep the other channel rules in `AGENTS.md`.

## Why

The repository is the shared record of decisions. A separate channel duplicates that record.

## What it means for agents

Write each decision in the repository. Link it in the related task thread.
Use `#tasks` for work and choices, `#releases` for releases, and `#general` for human chat.
Do not read or post in `#secrets`.
