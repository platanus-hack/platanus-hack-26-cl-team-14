# No tests

- Status: Accepted
- Date: 2026-11-20
- Source: `meetings/2026-11-20-kickoff.md`

## Decision

Agents do not write automated tests.

## Why

It is a hackathon. All the effort goes into the product.

## What it means for agents

Before a release, run the demo by hand and make sure that it works. Do not add test files.
