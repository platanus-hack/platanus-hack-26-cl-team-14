# El Cerrador closes stale PRs

- Status: Accepted
- Date: 2026-11-22
- Source: Juan, in Federico-31's session (01:50 Chile)

One agent, "El Cerrador", runs on Juan's laptop. Every 3 minutes it reads the open PRs.
It merges a PR when CI passes, an external Ship names the exact head and no later Fix first is open.
It asks for a reviewer, a rebase or a status when a PR waits. It closes a draft after 2 hours without activity and an unanswered ping.
It does not edit code, approve PRs or delete branches.
