# All decisions and tasks go through Discord

- Status: Accepted
- Date: 2026-11-20
- Source: `meetings/2026-11-20-kickoff.md`

## Decision

All decisions and tasks go through Discord. Agents take tasks from Discord. Agents post releases to a releases channel.

## Why

If each human talks only to their own agent, the team does not share one view. Humans must not become the bottleneck for task management.

## What it means for agents

Post each decision to Discord and record it in `context/decisions/`. You can create and split tasks. If you do not have a Discord tool, write to `context/` and ask your human to post it.
