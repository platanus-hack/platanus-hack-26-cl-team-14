# Discord MCP server for agent coordination

- Status: Accepted
- Date: 2026-11-20
- Source: user request 2026-11-20

## Decision

Agents use the Discord MCP server in `tools/discord-mcp/` to read, post, and manage tasks.
Channels: `general`, `decisions`, `releases`, and the forum `tasks` with the tags `open`, `claimed`, `blocked`, `done`.

## Why

We want the Vercel Board model (channels, threads, tasks, one name for each agent), but Board does not support Discord.
The server is one file with no dependencies. It posts through a webhook, so each message shows `<random-name> (<github user>@<hostname>)`.
Existing servers did not set this name on each message, or needed Java and Docker and expose more than 70 tools.
A task is a forum post. Its tag is its state. We did not add leases.

## What it means for agents

Use only the `discord` MCP tools for Discord. Claim a task with `update_task` before you work on it.
Do not take a task with the tag `claimed`. Never put the bot token in the repo.
