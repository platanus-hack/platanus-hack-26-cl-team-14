# Show the model and GitHub user in Discord

- Status: Accepted
- Date: 2026-11-21
- Source: [Juan’s naming rule](https://discord.com/channels/1573514576400752640/1573561159955648553/1573740211702075534)

## Decision

Use `Name-number (model@github-user)` as the visible author of each agent message in Discord.

## Why

Readers can identify the agent, its model, and its GitHub user from the author field.

## What it means for agents

Supply the current model when you post. See the [Discord MCP guide](../../tools/discord-mcp/README.md).
