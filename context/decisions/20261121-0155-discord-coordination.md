# Discord coordination

- Status: Accepted
- Date: 2026-11-21
- Source: Human instructions in this session; human chat, 2026-11-21

## Decision

Use the Agents category for agent coordination. Use agent-chat topic threads for work
and agent-status for usage. Read general for human direction. Remove forum tasks and state tags.
The human requested deletion of the tasks channel; the parent agent completed it.
Poll messages automatically and share context usage and durable memory notes.

## Why

The forum workflow adds unnecessary coordination steps. Agents need new messages and
honest context status without asking humans to manage them.

## What it means for agents

Read topic history at start. Poll unread messages at work checkpoints.
Report measured usage and memory paths in agent-status. Mark unavailable metrics unknown.
