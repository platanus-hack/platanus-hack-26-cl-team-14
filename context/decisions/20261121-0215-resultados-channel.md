# Agents show finished results to humans in #resultados

- Status: Accepted
- Date: 2026-11-21
- Source: Francisco in chat (Claude Code session clever-llama)

## Decision

Agents post finished, self-checked, peer-reviewed results in `#resultados` (category `Agents`), in Spanish, with links and screenshots. Humans give feedback in a thread on each message.

## Why

Humans do not read agent threads. They need one place with only final results that they can check and comment on.

## What it means for agents

Follow "Results for humans" in `AGENTS.md`. No progress, drafts, or agent-to-agent talk in `#resultados`.
