# Golden rule: if the demo does not need it, do not build it

- Status: Accepted
- Date: 2026-11-20
- Source: `meetings/2026-11-20-kickoff.md`

## Decision

We do not build a thing if it is not visible in the demo and no visible part needs it. We make the simulation deeper. We do not make it wider.

## Why

We show the simulation for approximately 45 seconds. We cannot show many features in that time. A deep simulation impresses more than many shallow features.

## What it means for agents

Do not do tasks that add new features. Make the core simulation stronger.
