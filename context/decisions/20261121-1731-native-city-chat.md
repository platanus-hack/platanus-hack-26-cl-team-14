# Ask the simulation from the city window

- Status: Accepted
- Source: [Juan’s decision and the panel brief](https://discord.com/channels/1573514576400752640/1573688247572238336/1573752380447789109)

The presenter types a question into a narrow panel on the right of the native city window. Enter sends the question to the local Codex or Claude CLI. The answer appears above the question box.

The CLI uses the presenter's existing login and the Santiago MCP server. The server sends the scenario to the same engine that the window watches. The city receives that change through its existing event stream. Typing in the panel leaves the camera and subway controls idle.
