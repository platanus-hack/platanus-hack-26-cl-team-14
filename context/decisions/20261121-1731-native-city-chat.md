# Open the city beside the presenter's terminal

- Status: Accepted
- Source: Juan’s revised decision in the [Corte 2 thread](https://discord.com/channels/1573514576400752640/1573688247572238336)

The launcher opens the native city on the left and a real terminal on the right. The presenter types into the interactive Claude Code or Codex CLI. The CLI supplies its own interface, conversation history, and login.

The launcher configures the Santiago MCP for this session. The server sends the scenario to the same engine that the city watches. The viewer receives the result through its existing event stream.
